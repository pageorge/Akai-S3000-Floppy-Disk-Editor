# ExternalResources

Archived reference material for the Akai S3000 disk format.
Copies kept here in case originals go offline.

## Files

### S3000-format-ohsaki.txt
Hiroyuki Ohsaki's S3000 disk and file format documentation.
Original: https://lsnl.jp/~ohsaki/software/akaitools/S3000-format.html
Reverse-engineered 1993, published 2019. Primary external reference for this project.

### akaiutil_file.h
Key header from the akaiutil project by Klaus Michael Indlekofer.
Original: https://github.com/Midi-In/akaiutil/blob/master/akaiutil_file.h
C structs for S900/S1000/S3000 sample, program and keygroup formats.
One of the first sources used when starting this project.

### akai-fs-notes.md
Notes from the akai-fs project by Tom Dial.
Original: https://github.com/dialtr/akai-fs
FUSE filesystem wrapper around akaiutil.
